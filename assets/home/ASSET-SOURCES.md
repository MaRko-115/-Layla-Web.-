# Home asset acquisition notes

## First verified furnishing source
- Kenney Furniture Kit: https://kenney.nl/assets/furniture-kit
- License shown by the publisher: CC0 1.0
- Pack listing: 140 furniture/interior assets
- Official formats include glTF/FBX/Blend (verify exact contents before using)
- Useful categories: sofa/chairs, tables, bed, bookcase, kitchen props

A GLB convenience mirror is listed here:
https://eclair-assets.itch.io/furniture-kit-glb-pack-140-free-cc0-3d-models
It states that it is based on Kenney's CC0 pack. Prefer the official Kenney source where practical; if using the mirror, retain its license/readme and verify the archive before shipping.

## Character direction
The current procedural character is not an anime-quality production model. Do not silently replace her with an unrelated blocky/minion character. A candidate free CC0 rigged character creator is:
https://grab3d.com/tools/character-mixer/
It offers modular stylized characters and GLB/VRM export, but its current visual style is cozy/blocky/low-poly rather than anime. Treat it as a technical fallback only, not an approved final Layla model.

## Required before importing any asset
1. Preview the actual model, not only the catalog thumbnail.
2. Verify the license on the source page and keep the license file.
3. Check GLB/GLTF compatibility with Three.js 0.180.0.
4. Check file size, materials, skeleton, animation clips, and scale.
5. Do not commit large archives or claim assets are installed until they have been downloaded and validated.

## Target home layout
One connected compact house: living room, library, bedroom, and kitchen. Use ready-made furniture/props, with a consistent stylized visual treatment. Keep the old outdoor valley as a fallback until the interior renders and controls are verified.
