# Layla Web — عالم ليلى

مشروع عالم ثلاثي الأبعاد تفاعلي يعمل مباشرة في المتصفح باستخدام Three.js.

## الحالة الحالية

**المرحلة 0 — تأسيس العالم**
- مشهد ثلاثي الأبعاد بإضاءة نهارية وضباب جوي وظلال.
- وادٍ طبيعي بتضاريس متدرجة، أشجار، نباتات، صخور، بركة ماء، كوخ وفوانيس.
- شخصية ليلى إجرائية مستقلة عن بيئة العالم.
- كاميرا منظور ثالث، حركة WASD والأسهم، قفز، تدوير كاميرا بالسحب.
- دعم عصا حركة للمس والتفاعل مع ليلى.
- واجهة عربية RTL.

## التشغيل

لا تفتح `index.html` عبر `file://`؛ استخدم خادماً محلياً أو استضافة صفحات ثابتة.

مثال باستخدام Node.js:

```bash
npx serve .
```

ثم افتح العنوان الذي يظهر في الطرفية.

## البنية

```
index.html
styles.css
src/
  main.js       # دورة الرسم والتحكم والتفاعل
  world.js      # البيئة والإضاءة والتضاريس
  character.js  # بناء شخصية ليلى الإجرائي
```

## التقنية

- Three.js 0.180.0 عبر ES Modules.
- لا توجد مفاتيح API أو خدمات مدفوعة.
- لا توجد ملفات نماذج خارجية مطلوبة في المرحلة الحالية.

## خارطة التطوير

1. تأسيس العالم والكاميرا والتحكم والشخصية.
2. تحسين التشريح والوجه والشعر والملابس ونظام الحركة.
3. إضافة مناطق قابلة للاستكشاف وتفاصيل بيئية وصوتيات.
4. نظام تفاعل وحوار ومهام وحفظ محلي.
5. تحميل نماذج GLB/VRM كخيار إضافي بعد تثبيت خطوط التشغيل.

> هذه بداية تقنية قابلة للتشغيل وليست ادعاءً بأن العالم أو الشخصية اكتملَا. ستضاف الأنظمة على مراحل مع اختبار كل مرحلة.
